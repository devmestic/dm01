# Notices

Rhodes Reader KR is an independent, unofficial Android reader.

The application code and build tooling in this repository are separate from the game content they can process. Arknights story text, images, audio, character art, logos and other original game assets remain the property of their respective rights holders, including Hypergryph / Studio Montagne / Yostar where applicable.

Upstream community repositories used by the build pipeline are credited in README.md. A public GitHub repository or an open-source license for a reader/tool does not automatically relicense original game media. For that reason, full-media APKs are generated as personal build artifacts rather than automatically published as public releases.
